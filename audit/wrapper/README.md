# Audit capture wrapper

Put `audit/wrapper/` before the real capture directory on the blind agent's `PATH`; its executable is named `capture`. Set `AUDIT_TRANSCRIPT` to the run's `transcript.ndjson` and `AUDIT_RUN_ID` to the coordinator's run ID. The wrapper invokes `/Users/silasrhyneer/Code/cli/capture/bin/capture` unless `AUDIT_CAPTURE_BIN` names a test binary.

The wrapper forwards argv and the complete environment to the child, pipes stdin unchanged, and streams stdout and stderr immediately without rewriting, buffering to EOF, or truncating either channel. It preserves child exit codes and maps a child SIGINT/SIGTERM termination to the POSIX process status 130/143 after recording the signal. `wrapper.test.mjs` proves byte-identical real-binary output for root, branch, and leaf help, an unknown command, and `lib list`; it also proves streaming and cross-channel ordering, stdin bytes, ordinary and non-standard exits, signal forwarding, concurrent ordinal allocation, and byte counting.

Each completed call appends one newline-terminated JSON event through one `O_APPEND` write. A lock serializes appends, so ordinal allocation follows transcript order even when invocations overlap. Artifact extraction recognizes POSIX absolute paths in whitespace-delimited output tokens, including `path=/…` fields and terminal prose punctuation, and retains only exact candidates that exist after the child returns. It intentionally accepts false negatives rather than inventing paths.

The transcript is mandatory. Before spawning a child, the wrapper verifies it can open `AUDIT_TRANSCRIPT` for append; a failure writes `${AUDIT_TRANSCRIPT}.failure` when possible, emits a wrapper configuration error, exits 70, and never starts the child. If a later recording failure occurs after the child ran (for example, a full filesystem), the wrapper preserves the child's output and status and writes that same `.failure` sidecar. The coordinator must reject any run with this marker; `reconcile()` enforces that check before CDP accounting so a grader cannot consume an incomplete transcript. The marker is the wrapper's separate failure channel and is never injected into child stdout or stderr.
